# 🚀 Personal Developer Portfolio

A modern, responsive, and lightweight personal portfolio website built using **HTML, CSS, and JavaScript**.  
Designed to showcase skills, projects, and experience in a clean and visually appealing way.

---

## ✨ Features

- ⚡ Fully responsive design (mobile, tablet, desktop)
- 🎨 Modern UI with clean layout
- 🌈 Smooth animations and transitions
- 🧠 Simple and optimized vanilla JavaScript (no frameworks)
- 🖼️ Project showcase section
- 📬 Contact section (email/social links)
- 🚀 Fast loading and lightweight

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (Vanilla JS)
