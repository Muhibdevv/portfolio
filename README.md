# 🚀 Muhib Ullah – Developer Portfolio

A modern, responsive, and performance-focused personal portfolio website built using HTML, CSS, and JavaScript. This project showcases my skills, projects, and experience as a frontend developer in a clean and interactive way.

---

## 🌟 Live Preview

https://muhib.tech

---

## 👨‍💻 About This Project

This portfolio is designed to reflect a modern developer identity with a strong focus on clean UI/UX, fast performance, responsive layouts, smooth animations, and a minimal yet impactful design approach.

The goal is to keep everything lightweight while still feeling premium and visually engaging.

---

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Modern UI with glassmorphism effects
- Smooth scroll animations and transitions
- Vanilla JavaScript interactivity (no frameworks)
- Project showcase section
- Contact section with email and social links
- Fast loading and optimized performance
- Subtle hover effects and micro-interactions

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
